# Skënderbeu – Mbrojtja e Krujës

Lojë 3D në shfletues (WebGL 2): si Gjergj Kastrioti Skënderbeu mbi kalë, mbro portën e Krujës gjatë dhjetë valëve. Funksionon në kompjuter dhe në celular.

A 3D browser game (WebGL 2): ride as Skanderbeg and defend the gate of Krujë for ten waves. Everything is in one self-contained `index.html`.
